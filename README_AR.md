# موسوعة الجزائر والعالم — Android

نسخة مطوّرة من المشروع المرفوع، مبنية بـ Kotlin وJetpack Compose.

## ما تم إصلاحه وإضافته
- تحديث التطبيق إلى الإصدار 1.1.0.
- إدراج قائمة الولايات الجزائرية الـ58 بدلاً من القائمة الجزئية السابقة.
- تحسين البحث العام داخل الأقسام.
- تحسين الواجهة العربية واتجاه RTL والألوان الأزرق والذهبي.
- إضافة أيقونة تطبيق داخلية.
- إضافة شاشة لحساب المسافة الجوية التقريبية بين 12 مدينة جزائرية مدرجة.
- تحسين GitHub Actions لتثبيت Gradle 8.9 صراحةً وبناء APK Debug ثم رفعه كـ Artifact.
- ضبط JDK 17 وخصائص Java/Kotlin لتوافق Android Gradle Plugin 8.7.3.

## مهم: حدود البيانات الحالية
هذه النسخة ليست بعد موسوعة مكتملة البيانات. قائمة الولايات الـ58 موجودة، لكن الدوائر والبلديات الـ1541 لم تُدرج بعد كقاعدة بيانات موثقة. قسم دول العالم يحتوي حالياً على 25 دولة فقط، وليس كل دول العالم. كما أن بيانات الديانات لم تُدرج لأن عرضها يحتاج مصادر دقيقة وتجنب التعميم على سكان الدولة. بيانات المسافات متاحة لـ12 مدينة فقط وهي مسافات خط مستقيم تقريبية وليست مسافات طرق. لم نضع أرقاماً أو معلومات غير متحقق منها لملء الفراغات.

## البناء عبر GitHub من الهاتف
1. أنشئ مستودعاً جديداً في GitHub.
2. ارفع محتويات هذا المجلد كاملة إلى جذر المستودع، بحيث يظهر `settings.gradle.kts` مباشرة في الصفحة الرئيسية.
3. افتح تبويب Actions.
4. اختر `Build Android APK` ثم `Run workflow`، أو انتظر التشغيل بعد رفع الملفات إلى فرع `main`.
5. بعد نجاح البناء افتح نتيجة التشغيل ثم قسم Artifacts ونزّل `Mousouat-Algeria-World-debug`.

## المتطلبات
- Android Studio/Gradle: Android Gradle Plugin 8.7.3 وGradle 8.9.
- JDK 17.
- minSdk 24، targetSdk 35، compileSdk 35.

## ملاحظة عن الاختبار
تمت مراجعة ملفات المشروع وتحديث إعدادات البناء. لم يتم تنفيذ بناء Android فعلي في بيئة هذه المحادثة، لذلك لا أصف ملف APK بأنه اختُبر أو أنه جاهز للتثبيت قبل نجاح GitHub Actions.

## الهوية البصرية المعتمدة
- تم اعتماد الصورة الأولى كصورة الهوية/الغلاف الظاهر أعلى الشاشة الرئيسية.
- تم حفظ الصورة الثانية كمرجع تصميم معتمد داخل مجلد `design/`، وأعيد بناء بطاقات الأقسام بألوان كحلي وأزرق وذهبي مع إبقاء العناصر تفاعلية.
- صور التصميم محفوظة داخل المشروع ولا تحتاج إلى اتصال بالإنترنت.
